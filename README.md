# Подешевело! — бот-трекер цен (WB / Ozon / Avito)

Присылаешь боту ссылку на товар — он следит за ценой и пишет, когда она
упала.

## Структура

```
podeshevelo_bot/
├── bot.py                     # точка входа: бот + фоновая проверка цен
├── config.py                   # настройки из .env
├── db.py                       # SQLite: users, watches
├── handlers/
│   ├── start.py                # /start, /help, /subscribe (заглушка)
│   ├── track.py                 # приём ссылки, добавление отслеживания
│   └── list.py                   # /list — список отслеживаний, удаление
└── services/
    ├── marketplaces/
    │   ├── wildberries.py        # card.wb.ru API
    │   ├── ozon.py                 # best-effort (антибот, может отваливаться)
    │   └── avito.py                 # best-effort (антибот, может отваливаться)
    └── price_checker.py            # фоновый цикл проверки цен раз в 5 минут
```

## Установка и запуск

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

`.env` уже заполнен токеном бота (`@podeshevelo_bot`). Дальше просто:

```bash
python bot.py
```

Бот поднимется через long polling — сервер и домен для этого не нужны,
достаточно, чтобы был запущен процесс на этом компьютере.

## Тарифы (пока без реальной оплаты)

- Бесплатно: до 3 отслеживаний, проверка раз в 6 часов.
- Платно: безлимит, проверка раз в 30 минут — `/subscribe` сейчас просто
  сообщает "скоро". Оплату подключим через Robokassa, когда будет сервер
  (переиспользуем готовый паттерн из `tgbot/services/payments.py`).

## Известные ограничения

- **Wildberries** — стабильно, официальный полу-публичный JSON API.
- **Ozon / Avito** — сайты защищены от скрапинга (антибот/капча). Парсер
  делает best-effort через встроенный JSON на странице; если не смог
  распарсить — бот не падает, просто помечает отслеживание как временно
  недоступное и пробует снова на следующем цикле. Если антибот начнёт
  блокировать чаще — можно перейти на headless-браузер (Playwright) или
  прокси, но это отдельная задача.
